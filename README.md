# Qalam 2.0 Product Page

A static product page for Qalam 2.0, a browser extension for NUST students. Built with plain HTML and CSS.

## What it covers

- Semantic HTML: `header`, `nav`, `main`, `section`, `article`, `figure`, `details`, `footer`
- Box model: `border-box` reset with consistent margin, padding and borders
- Flexbox: navbar, hero, FAQ list and footer
- Positioning: `relative` parents with `absolute` badges, popup image and captions, plus a `sticky` navbar
- CSS Grid: responsive feature cards, steps and screenshot gallery
- Media queries at 900px and 700px

## Run it

Open `index.html` in a browser. There is nothing to install.

## Git workflow

Each change was built on its own branch and merged into `main` through a pull request.
